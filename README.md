1. Pengertian Bootsrap
Bootstrap adalah framework CSS yang digunakan untuk mempermudah pembuatan dan pengembangan tampilan website. Bootstrap menyediakan berbagai komponen dan class siap pakai, seperti navbar, tombol, form, card, dan grid. Bootstrap juga membantu membuat website yang responsif sehingga tampilannya dapat menyesuaikan ukuran layar perangkat, seperti komputer, tablet, dan smartphone.

2. Memasang Boostrap
   Ada beberapa cara untuk menggunakan Bootstrap pada project, yaitu:
1.	Menggunakan CDN (Content Delivery Network): Menghubungkan file CSS dan JavaScript Bootstrap melalui URL CDN tanpa perlu mengunduh file Bootstrap.
2.	Mengunduh file Bootstrap: Mengunduh file Bootstrap dari situs resminya, kemudian menghubungkan file CSS dan JavaScript tersebut ke dalam project.
3.	Menggunakan package manager: Memasang Bootstrap melalui npm atau package manager lainnya agar dapat dikelola sebagai bagian dari project.
4.	Menggunakan framework atau bundler: Mengintegrasikan Bootstrap melalui tools seperti Vite atau Webpack untuk mengelola aset project.

3. Grid dan Breakpoint
   Grid adalah sistem tata letak Bootstrap yang membagi halaman menjadi 12 kolom untuk mengatur posisi dan lebar elemen. Grid menggunakan class seperti container, row, dan col agar tata letak website lebih terstruktur.
Breakpoint adalah batas ukuran layar yang digunakan untuk menyesuaikan tampilan website berdasarkan lebar perangkat. Bootstrap menyediakan breakpoint seperti sm, md, lg, xl, dan xxl.

4. Class Boostrap
   container : Membuat wadah konten dengan lebar yang menyesuaikan breakpoint.
   row : Membuat baris dalam sistem grid.
   col -md-6 : Membuat kolom selebar setengah baris pada layar medium ke atas.
   btn btn-primary : Membuat tombol dengan warna utama Bootstrap.
   form-control : Memberikan tampilan standar Bootstrap pada input form.
   text-center : Membuat teks rata tengah.
   bg-success : Memberikan warna latar belakang hijau.
   mt-3 : Memberikan margin atas dengan ukuran spacing tertentu.

5. Gambar Responsif
   Untuk membuat gambar responsif menggunakan Bootstrap, kita dapat menambahkan class img-fluid pada elemen <img>. Class ini membuat gambar menyesuaikan lebar wadahnya tanpa mengubah proporsi gambar
